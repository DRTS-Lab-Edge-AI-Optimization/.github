# DRTS Lab Edge AI Optimization

**University of Tehran DRTS Lab research on efficient and deployable artificial intelligence at the edge.**

This organization hosts reproducible experiments, evaluation tools, and edge-device implementations from DRTS Lab.

## Projects

| Repository | Description |
| --- | --- |
| [ufldv1-compression](https://github.com/DRTS-Lab-Edge-AI-Optimization/ufldv1-compression) | Compression experiments for Ultra-Fast-Lane-Detection v1 (UFLD v1). |

## Reproducibility

Project repositories document software versions, hardware, data preparation, commands, and evaluation metrics. Dataset files and model weights are not hosted here unless redistribution is permitted.

For questions, open an issue in the relevant project repository.
